## About

This project provides a polished login and sign-in interface with a responsive card layout, smooth spacing, and a sleek dark gradient background. It is ideal for learning front-end form design, page linking, and responsive styling.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Separate login and sign-in pages
- Bootstrap-powered form styling
- Font Awesome form icons
- Clean navigation between authentication pages
- Simple and lightweight front-end structure

## Run Locally

From the project folder, start a local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/login.html
```

## Notes

The page is fully static and can be extended with:

- form validation
- backend authentication integration
- password visibility toggle
- animated transitions
